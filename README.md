# 我的个人网页

> Oracle 数据库运维笔记与前端学习记录

## 站点简介

「我的个人网页」是一个**纯静态、零构建**的个人站点，用于沉淀作者的运维实战经验与前端自学笔记。站点不依赖任何后端与框架，全部内容由 Markdown 文档驱动、浏览器端渲染，轻量、易维护、可长期免费托管。

## 站点定位与核心功能

定位：面向技术人的个人知识库与成长记录，强调「内容可读、结构清晰、易于维护」。

- **文章列表**：按时间倒序展示全部文章，包含标题、日期、标签与摘要。
- **文章详情**：基于 Markdown 渲染，集成代码高亮（highlight.js）与内容净化（DOMPurify），兼顾可读性与安全性。
- **标签分类**：提供标签总览（`#/tags`）与按标签筛选（`#/tag/:名称`），快速检索同主题内容。
- **文章搜索**：列表页与标签页支持按标题、摘要、标签实时过滤，关键词在同一列表内保留。
- **文章目录**：详情页由 `h2/h3` 自动生成目录，支持锚点跳转与滚动高亮。
- **上下篇导航**：文末提供「较新一篇 / 较早一篇」快速跳转。
- **阅读辅助**：顶部阅读进度条、文首阅读时长预估、代码块一键复制。
- **关于页面**：介绍作者背景与联系方式。
- **工具箱**：聚合常用在线工具的外链入口，便于日常取用。

## 主要使用方式与访问路径

本站采用前端哈希路由（URL 形如 `#/...`），无需服务端配置，刷新不会 404。

| 页面 | 路径 |
|------|------|
| 首页（文章列表） | `/` |
| 文章详情 | `/post/:slug`（如 `/post/oracle-archivelog-cleanup`） |
| 标签总览 | `/tags` |
| 标签筛选 | `/tag/:名称` |
| 关于 | `/about` |
| 工具箱 | `/tools` |

线上访问地址：https://liupeng2268.github.io/

### 本地预览

本站通过 `fetch` 异步加载 Markdown 与数据，**必须通过 HTTP 服务访问**，不能直接双击用 `file://` 打开（会被浏览器 CORS 拦截）。

```bash
# 在项目根目录执行
python -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

## 内容维护

- **新增文章**：在 `articles/` 下新建 `.md` 文件（含 front-matter 元数据），并在 `data/posts.json` 添加对应索引。
- **新增工具**：编辑 `data/tools.json` 追加条目。

## 技术栈

- 纯静态 HTML / CSS / JavaScript（ES Module，无框架、无构建步骤）
- 渲染：marked + DOMPurify + highlight.js（均通过 CDN 引入）
- 数据层带会话内缓存，目录跳转不重复请求
- 部署：GitHub Pages，根目录 `.nojekyll` 禁用 Jekyll
