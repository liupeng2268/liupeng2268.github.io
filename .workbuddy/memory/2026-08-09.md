## 个人主页静态站点（「我的个人网页」）
- 需求：文章列表/详情、标签分类、关于页、工具箱页签，支持 Markdown 渲染。纯静态零构建，部署 GitHub Pages。
- 技术决策：vanilla HTML/CSS/JS + 哈希路由（#/...）+ marked@12 + DOMPurify@3 + highlight.js@11（均 CDN）。front-matter 自解析。资源全用相对路径，根目录放 .nojekyll 禁用 Jekyll。
- 设计：设计师锁定 Design Token（沉稳蓝 #2563eb 主色，Lucide SVG 图标，仅亮色，响应式）。
- 预置：2 篇文章（Oracle 归档日志清理 / 前端 Markdown 渲染入门）、工具箱 7 个链接（用户给的 sps.yy-gp.com/hagu9/i.html + MDN / 菜鸟教程 / Can I Use / Regex101 / JSON 格式化 / GitHub）。
- 前端工程师额外新增 #/tags 标签总览路由（原路由仅 #/tag/:name）。
- P0 门禁（禁 emoji 图标 / 紫粉渐变 / 裸色值 / 弹跳缓动）已独立校验通过。
- 本地预览需 HTTP 服务（python -m http.server），不能用 file:// 直开（fetch 会被 CORS 拦）。
